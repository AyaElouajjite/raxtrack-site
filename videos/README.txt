RaxTrack promo videos, hosted here so Buffer can fetch them for scheduled posts.

Each .mp4 in this folder is served at:
  https://ayaelouajjite.github.io/raxtrack-site/videos/<file-name>.mp4

Rules:
- .mp4 (H.264), vertical 1080x1920, under ~50 MB each (GitHub blocks files over 100 MB).
- Lowercase names, no spaces: 2026-11-20-rest-timer.mp4
- Don't delete or rename a video until its scheduled post has gone out.
